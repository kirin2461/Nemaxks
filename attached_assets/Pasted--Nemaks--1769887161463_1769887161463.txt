## 📢 Типы рекламы в Nemaks

| Тип рекламы | Описание | Кто видит | Условия |
|-------------|----------|-----------|---------|
| **Системная (платформенная)** | Баннеры, уведомления от Nemaks | Все без лицензии | Отключается при покупке лицензии |
| **Пользовательская** | Рекламные посты, продвижение гильдий | Все пользователи | Согласование с Super Admin |

## 🛠️ Реализация пользовательской рекламы

### Модель для заявок на рекламу:
```go
type AdRequest struct {
    ID           uuid.UUID
    UserID       uuid.UUID  // Кто подал заявку
    Type         string     // POST, GUILD, BANNER
    Content      string     // Описание/контент рекламы
    TargetURL    string     // Ссылка (если есть)
    Status       string     // PENDING, APPROVED, REJECTED
    
    // Согласование
    ReviewedBy   *uuid.UUID // Super Admin который рассмотрел
    ReviewedAt   *time.Time
    ReviewNote   string     // Комментарий от админа
    
    // Условия (заполняет Super Admin)
    Price        *int       // Цена в Nemcoins или рублях
    Duration     *int       // Длительность показа (дней)
    
    CreatedAt    time.Time
}
```

### Страница в админке Super Admin:
- Список заявок на рекламу
- Одобрение/отклонение
- Установка условий (цена, срок)
