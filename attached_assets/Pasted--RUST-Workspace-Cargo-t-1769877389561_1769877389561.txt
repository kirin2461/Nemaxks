## 🔴 КРИТИЧЕСКИЕ УЯЗВИМОСТИ

### 1. **SQL INJECTION в audit-service** [replit](https://replit.com/t/ss-12/repls/Nemaxks-3#rust-services/audit-service/src/main.rs)
**Файл:** `rust-services/audit-service/src/main.rs` (строки 76, 79)

```rust
// УЯЗВИМЫЙ КОД:
filters.push(format!(" AND user_id = {}", req.user_id));
filters.push(format!(" AND action = '{}'", req.action));
```

**Проблема:** Прямая интерполяция пользовательского ввода в SQL запрос.
**Риск:** Критический - злоумышленник может выполнить произвольный SQL.
**Решение:** Использовать параметризованные запросы через `.bind()`:
```rust
.bind(req.user_id)
.bind(&req.action)
```

### 2. **Hardcoded Database Credentials** [replit](https://replit.com/t/ss-12/repls/Nemaxks-3#rust-services/audit-service/src/main.rs)
**Файл:** `rust-services/audit-service/src/main.rs` (строка 174)

```rust
.unwrap_or_else(|_| "postgres://user:password@localhost:5432/nemaks".to_string());
```

**Проблема:** Дефолтные credentials в production коде.
**Риск:** Высокий - утечка credentials при деплое.
**Решение:** Удалить fallback или использовать безопасные дефолты.

## 🟠 АРХИТЕКТУРНЫЕ ПРОБЛЕМЫ

### 3. **Неиспользуемый Tantivy индекс** [replit](https://replit.com/t/ss-12/repls/Nemaxks-3#rust-services/search-service/src/main.rs)
**Файл:** `rust-services/search-service/src/main.rs` (строка 61)

```rust
// Fallback to SQL search if Tantivy index not ready
```

**Проблема:** Tantivy индекс инициализируется, но всегда используется SQL fallback.
**Влияние:** Потеря производительности полнотекстового поиска.
**Решение:** Реализовать полноценную интеграцию Tantivy поиска.

### 4. **Отсутствие health checks**
Оба сервиса не имеют endpoint для проверки здоровья.
**Решение:** Добавить gRPC health checking или HTTP endpoint.

### 5. **Жёсткий пул соединений**
```rust
.max_connections(10)
```
**Проблема:** Hardcoded лимит соединений не масштабируется.
**Решение:** Вынести в конфигурацию через environment variables.

## 🟡 ПОТЕНЦИАЛЬНЫЕ УЛУЧШЕНИЯ

### 6. **Отсутствие retry логики**
При недоступности базы данных сервис падает без попытки переподключения.

### 7. **Нет graceful shutdown**
Отсутствует обработка SIGTERM для корректного завершения.

### 8. **Статический путь индекса**
```rust
let index_path = "./data/search_index";
```
**Решение:** Конфигурируемый путь через env var.

### 9. **Отсутствие логирования**
Используется только `println!()` вместо структурированного логирования (tracing/log).

## 📝 ЗАКЛЮЧЕНИЕ

Rust микросервисы имеют **хорошую архитектурную основу** с использованием современного стека (Tonic, SQLx, Tantivy). Однако обнаружены **критические уязвимости безопасности** (SQL injection, hardcoded credentials), которые необходимо исправить перед production использованием. После устранения уязвимостей сервисы будут готовы к деплою.
