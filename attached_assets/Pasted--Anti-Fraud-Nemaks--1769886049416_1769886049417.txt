# Обновлённый план Anti-Fraud системы для Nemaks

## 🛡️ Комплексная система защиты от мошенников

### Фаза 1: Backend инфраструктура

**1. Модели данных (`models_fraud.go`):**
- `FraudAlert` - хранение алертов о подозрительной активности
- `FraudRule` - настраиваемые правила обнаружения
- `UserRiskScore` - оценка риска для каждого пользователя
- `SuspiciousActivity` - лог подозрительных действий
- `IPBlacklist` / `DeviceFingerprint` - блокировка по IP/устройству

**2. Handlers (`handlers_fraud.go`):**
- Обнаружение спама сообщений (flood detection)
- Обнаружение массовых приглашений в гильдии
- Детекция фишинговых ссылок
- Проверка подозрительных паттернов поведения
- API для управления fraud-алертами

**3. Middleware (`middleware_fraud.go`):**
- Rate limiting по IP/User
- Проверка device fingerprint
- Анализ геолокации (подозрительные входы)
- Проверка VPN/Proxy использования

***

### Фаза 2: Правила обнаружения

**Автоматические триггеры:**
1. **Спам-детекция:** >10 одинаковых сообщений за минуту
2. **Flood-защита:** >50 сообщений за 5 минут
3. **Фишинг-фильтр:** Проверка ссылок на известные фишинговые домены
4. **Массовые DM:** >20 DM разным пользователям за час
5. **Подозрительная регистрация:** Множественные аккаунты с одного IP
6. **Аномальная активность:** Резкое изменение паттерна поведения
7. **Scam-паттерны:** "Бесплатные Nemcoins", "Нажми сюда"

### 🔍 ДЕТЕКЦИЯ КЛЮЧЕВЫХ СЛОВ С УЧЁТОМ ОБФУСКАЦИИ (ОБНОВЛЕНО)

**Типы обфускации для обнаружения:**

**1. Замена букв на похожие символы (Homoglyph):**
```
ФСБ → ФС6, Ф$Б, ФC6, ФСВ (кириллица↔латиница)
FBI → F8I, FВI, FBl (l вместо I), ЕBI
МВД → MBД, МВD, M8Д, МВ∂
полиция → п0лиция, поlиция, пoлuцuя
```

**2. Разделение пробелами/символами:**
```
ФСБ → Ф С Б, Ф.С.Б, Ф-С-Б, Ф_С_Б
FBI → F B I, F.B.I., F-B-I
следователь → с.л.е.д.о.в.а.т.е.л.ь
```

**3. Вставка невидимых символов (Zero-Width):**
```
ФСБ → Ф​С​Б (zero-width space U+200B)
FBI → F‌B‌I (zero-width non-joiner U+200C)
полиция → по​ли​ция
```

**4. Замена на транслит/фонетика:**
```
ФСБ → FSB, эфэсбэ, фээсбэ
FBI → эфбиай, фбр (ошибочное)
полиция → police, politsiya, полис
следователь → sledovatel, следак
```

**5. Использование эмодзи/символов:**
```
ФСБ → 🇫🇸🇧, Ф🅂Б, ФⓈБ
полиция → 👮полиция, 🚔служба
капитан → ⭐капитан, 🎖️капитан
```

**6. Намеренные опечатки (Typosquatting):**
```
ФСБ → ФБС, ФСП, ВСБ, ФЦБ
FBI → FIB, FBL, BFI, FNI
полиция → полицыя, палиция, поліція
следователь → следаватель, следователь
```

**7. Сокращения и аббревиатуры:**
```
ФСБ → федералы, контора, органы, комитет
МВД → менты, мусора, легавые (+ вежливые варианты)
FBI → бюро, федералы, фбр
```

**8. Leetspeak (1337):**
```
ФСБ → Ф5Б, Ф$Б
FBI → F81, PBI, F|3|
police → p0l1c3, pol!ce
```

**9. Перевёрнутый/зеркальный текст:**
```
ФСБ → БСФ (reversed), ꟻƆᙠ
FBI → IBF, ᴵᴮᶠ
```

**10. Unicode подмена (Confusables):**
```
ФСБ → ФЅВ (кириллица Ѕ вместо С)
FBI → ＦＢＩ (fullwidth), ℱℬℐ (script)
а → a, о → o, е → e (кириллица↔латиница)
```

### 🛠️ Алгоритм нормализации текста (`text_normalizer.go`):

```go
func NormalizeText(input string) string {
    // 1. Удаление zero-width символов
    // 2. Конвертация Unicode confusables в базовые
    // 3. Удаление пробелов/разделителей между буквами
    // 4. Нормализация кириллица↔латиница
    // 5. Приведение к lowercase
    // 6. Замена leetspeak на буквы
    // 7. Удаление эмодзи между буквами
    // 8. Исправление типичных опечаток
}
```

**Пример работы:**
```
Вход:  "Я с.о.т.р.у.д.н.и.к Ф​С​Б"
После: "я сотрудник фсб"

Вход:  "F.B.I. ag3nt here"  
После: "fbi agent here"

Вход:  "п0л1ц1я вызывает"
После: "полиция вызывает"
```
