# ЧАСТЬ 1: НАЧАЛО РАБОТЫ

## Что такое Nemaks?

Nemaks — это современная платформа для общения, похожая на Discord, но с дополнительными фишками:
- Общение в гильдиях (серверах) и личных сообщениях
- AI-ассистент Jarvis, который помогает с учёбой
- Геймификация — зарабатывай XP, получай уровни и достижения
- Образовательные инструменты — тетради, доски, редакторы кода
- Голосовые и видеочаты
- Полное шифрование личных сообщений

### Для кого Nemaks?

- **Школьники и студенты** — для учёбы и общения с одноклассниками
- **Геймеры** — для координации в играх и общения
- **Творческие люди** — для обмена идеями и проектами
- **Любые сообщества** — клубы по интересам, фан-группы, команды

### Чем Nemaks отличается от других платформ?

| Особенность | Nemaks | Discord | Telegram |
|-------------|--------|---------|----------|
| AI-ассистент (Jarvis) | ✅ | ❌ | ❌ |
| Образовательные инструменты | ✅ | ❌ | ❌ |
| Геймификация (XP, уровни) | ✅ | Частично | ❌ |
| E2E шифрование DM | ✅ | ❌ | ✅ |
| Голосовые каналы | ✅ | ✅ | Частично |
| Стоимость | Подписка | Бесплатно/Nitro | Бесплатно |

## Шаг 1: Получение лицензионного ключа

### Что такое лицензионный ключ?

Лицензионный ключ — это специальный код, который открывает доступ к платформе. Без него нельзя зарегистрироваться.

**Почему нужен ключ?**
- Защита от спама и ботов
- Контроль качества сообщества
- Финансирование развития платформы
- Включает Premium-функции

### Формат ключа

Ключ выглядит так: `NEMKS-XXXXX-XXXXX-XXXXX`

Пример: `NEMKS-TEST0-TEST0-TEST0`

**Структура ключа:**
```
NEMKS - TEST0 - TEST0 - TEST0
  │       │       │       │
  │       │       │       └── Третья группа (5 символов)
  │       │       └────────── Вторая группа (5 символов)  
  │       └────────────────── Первая группа (5 символов)
  └────────────────────────── Префикс (всегда NEMKS)
```

**Допустимые символы в ключе:**
- Заглавные буквы: A-Z
- Цифры: 0-9
- Дефисы между группами (обязательны)

**Примеры правильных ключей:**
- `NEMKS-ABCDE-12345-FGHIJ`
- `NEMKS-TEST0-TEST0-TEST0`
- `NEMKS-PRO26-YEAR1-XYZAB`

**Примеры НЕПРАВИЛЬНЫХ ключей:**
- `NEMKS-abcde-12345-fghij` (маленькие буквы)
- `NEMKSABCDE12345FGHIJ` (нет дефисов)
- `NEMKS-ABC-12345-FGHIJ` (неправильная длина группы)
- `nemks-TEST0-TEST0-TEST0` (маленький префикс)

### Типы ключей

| Тип | Срок действия | Цена | Что включено |
|-----|---------------|------|--------------|
| **Monthly** | 30 дней | 50₽ | Полный доступ на месяц |
| **Quarterly** | 90 дней | 125₽ | Экономия 17% vs Monthly |
| **Yearly** | 365 дней | 600₽ | Максимальная экономия (58%) |
| **Test** | 10 дней | Бесплатно | Для ознакомления |
| **Gift** | Разный | Подарок | Подарочные ключи |
| **Promo** | Разный | Бесплатно | Промо-акции |

### Где взять ключ?

**1. Тестовый ключ (бесплатно)**

Для первого знакомства с платформой используй:
```
NEMKS-TEST0-TEST0-TEST0
```

Этот ключ:
- Даёт 10 дней полного доступа
- Работает без ограничений
- Можно использовать один раз на аккаунт
- Включает все Premium-функции

**2. Покупка ключа**

На странице активации есть кнопки для покупки:
1. Выбери тариф (Monthly/Quarterly/Yearly)
2. Нажми "Купить"
3. Оплати удобным способом
4. Получи ключ на email или сразу на экране

**Способы оплаты:**
- Банковская карта (Visa, MasterCard, МИР)
- СБП (Система быстрых платежей)
- ЮMoney
- QIWI

**3. Получить от друга**

Кто-то может подарить тебе неиспользованный ключ:
- Попроси друга скинуть ключ в личку
- Или он может ввести твой email при покупке Gift-ключа

**4. Выиграть в розыгрыше**

Иногда ключи разыгрываются:
- В официальных каналах Nemaks
- На стримах и мероприятиях
- В партнёрских сообществах

**5. Промо-акции**

Следи за новостями — иногда бывают бесплатные ключи:
- На праздники
- При запуске новых функций
- Для студентов и школьников

### Что даёт ключ?

При активации ключа ты получаешь:

**Базовый доступ:**
- ✅ Регистрация аккаунта
- ✅ Вход в систему
- ✅ Создание и вступление в гильдии
- ✅ Текстовые и голосовые каналы
- ✅ Личные сообщения
- ✅ Добавление друзей

**Premium-функции (на весь срок ключа):**
- ✅ Отсутствие системной рекламы
- ✅ AI-ассистент Jarvis (полная версия)
- ✅ Образовательные инструменты (тетради, доски)
- ✅ Редакторы кода (Python, JavaScript, и др.)
- ✅ Загрузка файлов до 100 МБ (vs 25 МБ)
- ✅ HD видео в голосовых каналах
- ✅ Кастомные эмодзи
- ✅ Анимированный аватар
- ✅ Приоритетная поддержка

### Срок действия ключа

**Когда начинается отсчёт?**
- Срок начинается с момента АКТИВАЦИИ ключа
- Не с момента покупки!
- Можно купить ключ и активировать позже

**Пример:**
1. Купил ключ Monthly (30 дней) 1 января
2. Активировал 15 января
3. Доступ будет до 14 февраля

**Что происходит после окончания срока?**
1. Premium-функции отключаются
2. Базовый доступ остаётся
3. Твои данные сохраняются
4. Можно купить новый ключ и продолжить

**Можно ли продлить до окончания?**
- Да! Новый срок добавляется к оставшемуся
- Пример: осталось 10 дней + активировал Monthly = 40 дней

## Шаг 2: Активация ключа

### Пошаговая инструкция с картинками

**1. Открой страницу активации**

Перейди по ссылке: https://nemaxks-4.replit.app/activate

Ты увидишь страницу с:
- Полем для ввода ключа
- Информацией о тарифах
- Кнопками покупки

```
┌─────────────────────────────────────────────────┐
│                                                 │
│        🔑 Активация лицензии Nemaks            │
│                                                 │
│  ┌─────────────────────────────────────────┐   │
│  │ Введите ключ лицензии                   │   │
│  │ NEMKS-_____-_____-_____                 │   │
│  └─────────────────────────────────────────┘   │
│                                                 │
│            [ Активировать ]                     │
│                                                 │
│  ─────────────── или ───────────────            │
│                                                 │
│   [Monthly 50₽] [Quarterly 125₽] [Yearly 600₽] │
│                                                 │
└─────────────────────────────────────────────────┘
```

**2. Введи ключ**

В поле "Введите ключ лицензии" напиши свой ключ.

**Правила ввода:**
- Вводи ключ ТОЧНО как он написан
- Соблюдай регистр (БОЛЬШИЕ буквы)
- Дефисы ОБЯЗАТЕЛЬНЫ
- НЕ добавляй пробелы в начале или конце
- НЕ добавляй лишние символы

**Правильный ввод:**
```
NEMKS-TEST0-TEST0-TEST0
```

**Неправильный ввод:**
```
 NEMKS-TEST0-TEST0-TEST0     ← пробелы по краям
nemks-test0-test0-test0      ← маленькие буквы
NEMKS TEST0 TEST0 TEST0      ← пробелы вместо дефисов
NEMKS-TEST0-TEST0-TEST0.     ← точка в конце
```

**3. Нажми "Активировать"**

После нажатия система проверит ключ. Это занимает 1-3 секунды.

**4. Возможные результаты проверки**

| Сообщение | Причина | Что делать |
|-----------|---------|------------|
| ✅ "Ключ действителен" | Всё ок! | Переходи к регистрации |
| ❌ "Недействительный формат ключа" | Ошибка в написании | Проверь формат, дефисы, регистр |
| ❌ "Ключ не найден" | Ключ не существует | Проверь, правильно ли ввёл |
| ❌ "Ключ уже активирован" | Использован другим | Нужен новый ключ |
| ❌ "Ключ истёк" | Срок закончился | Нужен новый ключ |
| ⏳ "Сервер загружается" | Сервер стартует | Подожди 10-15 сек и повтори |
| ❌ "Ошибка сервера" | Технические проблемы | Подожди и попробуй позже |

**5. Переход к регистрации**

После успешной проверки:
1. Появится сообщение "Ключ действителен!"
2. Информация о типе ключа и сроке
3. Через 2-3 секунды автоматический переход на регистрацию
4. Или нажми кнопку "Продолжить" вручную

### Устранение проблем при активации

**Проблема: "Недействительный формат ключа"**

Решения:
1. Проверь, что все буквы ЗАГЛАВНЫЕ
2. Проверь, что есть все 3 дефиса
3. Проверь, что в каждой группе ровно 5 символов
4. Убери пробелы в начале и конце
5. Попробуй скопировать ключ заново

**Проблема: "Сервер загружается"**

Это нормально при первом обращении! Сервер "просыпается".

Решения:
1. Подожди 10-15 секунд
2. Попробуй снова
3. Не обновляй страницу слишком часто
4. Если не помогает — подожди 1-2 минуты

**Проблема: "Ключ уже активирован"**

Этот ключ использовал кто-то другой (или ты с другого аккаунта).

Решения:
1. Если это твой ключ — возможно, ты уже регистрировался
2. Попробуй войти вместо регистрации
3. Если ключ украли — обратись в поддержку
4. Купи новый ключ

**Проблема: Страница не загружается**

Решения:
1. Проверь интернет-соединение
2. Попробуй другой браузер
3. Очисти кэш браузера
4. Отключи VPN (если используешь)
5. Попробуй позже

## Шаг 3: Регистрация аккаунта

### Что нужно для регистрации

1. **Username (логин)** — твой уникальный никнейм
2. **Email** — электронная почта
3. **Пароль** — надёжный пароль
4. **Подтверждение пароля** — повторный ввод

### Username (логин)

**Что такое username?**
- Это твой уникальный идентификатор в системе
- По нему тебя находят другие пользователи
- Отображается везде: в чатах, профиле, списках

**Требования к username:**

| Правило | Пример ОК | Пример НЕ ОК |
|---------|-----------|--------------|
| От 3 до 20 символов | `Gamer` | `Go` (слишком короткий) |
| Только буквы, цифры, _ | `Cool_Gamer2026` | `Cool-Gamer` (дефис запрещён) |
| Не начинается с цифры | `Gamer123` | `123Gamer` |
| Уникальный | `MyUniqueNick` | `admin` (скорее всего занят) |

**Хорошие примеры username:**
```
CoolGamer2026
Masha_Cat
ProPlayer
Coder_Ivan
Music_Lover
ArtistAnya
```

**Плохие примеры username:**
```
123gamer         ← начинается с цифры
my name          ← содержит пробел
cool-gamer       ← содержит дефис
admin            ← скорее всего занят
a                ← слишком короткий
supermegaultracoolgamer2026pro ← слишком длинный
```

**Советы по выбору username:**
1. Придумай запоминающийся ник
2. Не используй личные данные (имя, фамилию, дату рождения)
3. Можно добавить цифры в конец, если ник занят
4. Username можно изменить позже (1 раз в 30 дней)

### Email (электронная почта)

**Зачем нужен email?**
- Восстановление пароля
- Важные уведомления
- Подтверждение безопасности
- Получение чеков об оплате

**Требования к email:**
- Настоящий, работающий адрес
- Ты должен иметь к нему доступ
- Правильный формат (example@domain.com)

**Какой email использовать?**

Рекомендуется:
- Gmail (google.com)
- Яндекс Почта (yandex.ru)
- Mail.ru
- Outlook (outlook.com)

Не рекомендуется:
- Временные почты (tempmail и т.д.) — могут не работать
- Рабочие почты — если потеряешь доступ к работе

**Важно:**
- Используй почту, к которой у тебя ПОСТОЯННЫЙ доступ
- Один email = один аккаунт
- Нельзя зарегистрировать два аккаунта на одну почту

### Пароль

**Требования к паролю:**
- Минимум 8 символов
- Хотя бы одна буква (a-z или A-Z)
- Хотя бы одна цифра (0-9)
- Рекомендуется: специальный символ (!@#$%^&*)

**Уровни надёжности пароля:**

| Уровень | Пример | Время взлома |
|---------|--------|--------------|
| Очень слабый | `123456` | Мгновенно |
| Слабый | `password123` | Минуты |
| Средний | `MyPass2026` | Часы |
| Сильный | `MyP@ss2026!` | Годы |
| Очень сильный | `Kf8$mN2#xQ9!pL` | Столетия |

**Плохие пароли (НИКОГДА не используй!):**
```
123456
password
qwerty
111111
iloveyou
admin
letmein
welcome
твоё_имя
твоя_дата_рождения
номер_телефона
```

**Хорошие пароли:**
```
MySecret2026!
Gamer#Pro$123
Ky7$mN2xQ9pL
StudyH@rd2026
```

**Как создать хороший пароль (метод фразы):**

1. Придумай фразу: "Я учусь в 9 классе школы 42"
2. Возьми первые буквы: "Яув9кш42"
3. Транслитерируй: "Yuv9ksh42"
4. Добавь символ: "Yuv9ksh42!"

Результат: `Yuv9ksh42!` — надёжный и запоминающийся!

**Как создать хороший пароль (метод случайных слов):**

1. Выбери 3-4 случайных слова: "кошка", "синий", "дождь"
2. Соедини: "КошкаСинийДождь"
3. Добавь цифры и символ: "КошкаСиний7Дождь!"
4. Транслитерируй: "KoshkaSiniy7Dozhd!"

**Где хранить пароль:**
- Менеджер паролей (Bitwarden, 1Password, LastPass)
- Зашифрованная заметка в телефоне
- Записать на бумаге и хранить в безопасном месте

**Где НЕ хранить пароль:**
- В незащищённых заметках
- В сообщениях самому себе
- В файле "пароли.txt" на рабочем столе
- В браузере (если компьютер общий)

   - Проверь правильность написания

   - Обрати внимание на индикатор надёжности

   - Должен совпадать с первым полем

### Возможные ошибки при регистрации

| Ошибка | Причина | Решение |
|--------|---------|---------|
| "Username уже занят" | Кто-то уже использует этот ник | Придумай другой или добавь цифры |
| "Email уже используется" | На эту почту уже есть аккаунт | Войди в существующий или используй другую почту |
| "Пароли не совпадают" | Разные пароли в двух полях | Введи одинаковый пароль в оба поля |
| "Пароль слишком простой" | Не соответствует требованиям | Добавь цифры и символы |
| "Неверный формат email" | Ошибка в написании почты | Проверь формат: example@domain.com |
| "Лицензия не активирована" | Не прошёл первый шаг | Вернись на страницу активации |

### Что происходит после регистрации

1. **Создаётся твой аккаунт**
   - Генерируется уникальный ID
   - Создаётся профиль
   - Выставляются настройки по умолчанию

2. **Активируется лицензия**
   - Ключ привязывается к аккаунту
   - Начинается отсчёт срока подписки
   - Активируются Premium-функции

3. **Автоматический вход**
   - Ты сразу попадаешь в систему
   - Не нужно вводить данные заново

4. **Приветственное сообщение**
   - Jarvis поздоровается и предложит помощь
   - Можно пройти краткое обучение

## Шаг 4: Первый вход

### Проблемы при входе и их решение

**"Неверный логин или пароль"**

Возможные причины:
1. Опечатка в username или email
2. Неправильный пароль
3. Включён Caps Lock
4. Аккаунт не существует

Решения:
1. Проверь правильность написания
2. Попробуй ввести email вместо username (или наоборот)
3. Проверь Caps Lock
4. Нажми "Забыли пароль?" для восстановления

**"Аккаунт заблокирован"**

Причины:
1. Слишком много неудачных попыток входа
2. Подозрительная активность
3. Нарушение правил платформы

Решения:
1. Подожди 15-30 минут (временная блокировка)
2. Попробуй снова
3. Если не помогает — обратись в поддержку

**"Сессия истекла"**

Это нормально после долгого отсутствия.
Просто войди заново.

**Забыл пароль**

1. На странице входа нажми "Забыли пароль?"
2. Введи email, указанный при регистрации
3. Проверь почту (включая папку "Спам")
4. Перейди по ссылке из письма
5. Придумай новый пароль

**Забыл username**

1. Попробуй войти по email
2. Или нажми "Забыли пароль?" — в письме будет указан username

**Не приходит письмо для восстановления**

1. Проверь папку "Спам"
2. Подожди 5-10 минут
3. Попробуй отправить снова
4. Проверь, правильный ли email ввёл
5. Обратись в поддержку

## Гильдии (Серверы)

### Что такое гильдия?

Гильдия — это сообщество людей с общими интересами. Как сервер в Discord или группа в Telegram, только круче.

**Примеры гильдий:**
- "Геймеры CS2" — для игроков в Counter-Strike
- "9А класс" — для одноклассников
- "Любители аниме" — для обсуждения аниме
- "Художники" — для творческих людей
- "Программисты" — для изучающих код

**Структура гильдии:**
```
📁 Гильдия "Геймеры"
│
├── 👤 Владелец: CoolAdmin
├── 👥 Участники: 150 человек
├── 📋 Роли: Админ, Модератор, Участник
│
├── 📁 Категория "Информация"
│   ├── 📜 #правила (только чтение)
│   ├── 📢 #новости (только чтение)
│   └── 💬 #знакомства
│
├── 📁 Категория "Общение"
│   ├── 💬 #общий-чат
│   ├── 💬 #оффтоп
│   └── 💬 #мемы
│
├── 📁 Категория "Игры"
│   ├── 💬 #minecraft
│   ├── 💬 #fortnite
│   ├── 💬 #valorant
│   ├── 🔊 Голосовой: Общий
│   └── 🔊 Голосовой: Игровая комната
│
└── 📁 Категория "Premium"
    ├── 💬 #vip-чат (только для ролей)
    └── 🔊 VIP Голосовой
```

### Форматирование текста

Nemaks поддерживает Markdown-форматирование:

| Синтаксис | Результат | Пример |
|-----------|-----------|--------|
| `*текст*` | *курсив* | `*важно*` → *важно* |
| `**текст**` | **жирный** | `**ВАЖНО**` → **ВАЖНО** |
| `***текст***` | ***жирный курсив*** | `***ого***` → ***ого*** |
| `~~текст~~` | ~~зачёркнутый~~ | `~~неправильно~~` → ~~неправильно~~ |
| `__текст__` | подчёркнутый | `__важно__` → <u>важно</u> |
| `` `код` `` | `код` | `` `console.log()` `` |
| `> текст` | цитата | `> Привет` → блок цитаты |
| `||текст||` | спойлер | `||секрет||` → скрытый текст |

**Блок кода (многострочный):**
```
\`\`\`язык
код
\`\`\`
```

Пример:
```
\`\`\`python
print("Hello, World!")
\`\`\`
```

Отобразится как подсвеченный Python-код.

**Поддерживаемые языки для подсветки:**
python, javascript, js, typescript, ts, html, css, json, java, c, cpp, csharp, go, rust, ruby, php, sql, bash, и многие другие.

### Шифрование личных сообщений

**Что такое E2E-шифрование:**
Все личные сообщения автоматически шифруются методом End-to-End (E2E).

**Как это работает:**
```
Ты: "Привет!"
    ↓ Шифрование на твоём устройстве
🔐 "x7Hk9mNp2qWe..."
    ↓ Передача через сервер
🔐 "x7Hk9mNp2qWe..."
    ↓ Расшифровка на устройстве друга
Друг видит: "Привет!"
```

**Кто НЕ может прочитать твои сообщения:**
- Хакеры — видят только шифр
- Администраторы Nemaks — не имеют ключей
- Государственные органы — без ключа не расшифруют
- Любые третьи лица

**Кто МОЖЕТ прочитать:**
- Ты
- Твой собеседник

**Индикатор шифрования:**
Иконка 🔒 в заголовке чата показывает, что чат зашифрован.

**Важно понимать:**
- Шифрование работает автоматически
- Не нужно ничего настраивать
- Ключи генерируются на устройстве
- При смене устройства нужен экспорт ключей

### Приоритет ролей

Роли имеют иерархию — кто выше в списке, тот "главнее".

```
Роли (сверху вниз по приоритету):
1. Owner        ← самый высокий приоритет
2. Admin
3. Moderator
4. VIP
5. Member
6. @everyone   ← самый низкий приоритет
```

**Правила приоритета:**
- Ты можешь управлять только ролями НИЖЕ твоей
- Цвет никнейма берётся от ВЫСШЕЙ роли
- При конфликте прав побеждает РАЗРЕШИТЬ

**Пример:**
Если у тебя роли "VIP" и "Member":
- VIP: Цвет золотой, можно прикреплять файлы
- Member: Цвет серый, нельзя прикреплять файлы
- Результат: Цвет золотой (от VIP), МОЖНО прикреплять файлы

## Поиск

### Быстрый поиск (Ctrl+K)

Нажми `Ctrl+K` (или `Cmd+K` на Mac) для открытия универсального поиска.

**Что можно найти:**
- Пользователей по username
- Каналы по названию  
- Гильдии
- Сообщения
- Настройки
- Команды

**Как пользоваться:**
1. Нажми Ctrl+K
2. Начни вводить запрос
3. Результаты появляются мгновенно
4. Используй стрелки для навигации
5. Enter для выбора

### Поиск по сообщениям

В каждом канале есть кнопка поиска 🔍

**Базовый поиск:**
Просто введи слово или фразу.

**Продвинутые фильтры:**

| Фильтр | Пример | Описание |
|--------|--------|----------|
| `from:` | `from:CoolGamer` | Сообщения от конкретного пользователя |
| `mentions:` | `mentions:me` | Сообщения с упоминанием тебя |
| `has:` | `has:image` | Сообщения с вложениями |
| `before:` | `before:2026-01-01` | Сообщения до даты |
| `after:` | `after:2026-01-01` | Сообщения после даты |
| `during:` | `during:2026-01-15` | Сообщения за конкретный день |
| `in:` | `in:общий-чат` | Сообщения в конкретном канале |
| `pinned:` | `pinned:true` | Только закреплённые |

**Значения для `has:`:**
- `has:image` — изображения
- `has:video` — видео
- `has:file` — любые файлы
- `has:link` — ссылки
- `has:embed` — встроенный контент

**Комбинирование фильтров:**
```
from:CoolGamer has:image after:2026-01-01
```
Найдёт все картинки от CoolGamer после 1 января 2026.

```
in:общий-чат mentions:me has:link
```
Найдёт сообщения в #общий-чат, где тебя упоминают и есть ссылка.

## Надёжный пароль

### Анатомия хорошего пароля

**Плохой пароль:**
```
123456        ← Самый популярный, взламывается мгновенно
password      ← Второй по популярности
qwerty        ← Клавиатурный паттерн
iloveyou      ← Популярная фраза
admin         ← Стандартное слово
```

**Средний пароль:**
```
Password123   ← Предсказуемый паттерн
MyName2006    ← Личные данные легко угадать
Summer2026!   ← Сезон + год = предсказуемо
```

**Хороший пароль:**
```
Kf8$mN2#xQ9!pL    ← Случайные символы
Correct-Horse-Battery-Staple  ← Случайные слова
MoyKot!Lyubit#Rybu2026  ← Фраза с модификациями
```

### Требования к паролю

**Минимальные требования Nemaks:**
- Минимум 8 символов
- Хотя бы 1 буква
- Хотя бы 1 цифра

**Рекомендации для максимальной безопасности:**
- 12+ символов
- Смесь БОЛЬШИХ и маленьких букв
- Цифры
- Специальные символы (!@#$%^&*()_+-=)
- НЕ словарные слова
- НЕ личные данные

### Время взлома пароля

| Пароль | Тип | Время взлома |
|--------|-----|--------------|
| `123456` | Популярный | Мгновенно |
| `password` | Словарный | Мгновенно |
| `alex2006` | Имя+год | Секунды |
| `MyPass123` | Простой | Минуты |
| `MyP@ss2026!` | Средний | Часы |
| `Kf8$mN2#xQ9!` | Сложный | Годы |
| `Correct-Horse-Battery-Staple` | Длинный | Столетия |

### Как создать надёжный пароль

**Метод 1: Фраза-аббревиатура**

1. Придумай запоминающуюся фразу:
   `"Мой кот Барсик родился 15 марта 2020 года!"`

2. Возьми первые буквы каждого слова:
   `"МкБр15м2020г!"`

3. Транслитерируй:
   `"MkBr15m2020g!"`

4. Результат: `MkBr15m2020g!` — надёжный и запоминающийся!

**Метод 2: Случайные слова**

1. Выбери 4-5 случайных слов:
   `кошка`, `синий`, `дождь`, `кактус`

2. Соедини:
   `КошкаСинийДождьКактус`

3. Добавь цифру и символ:
   `Кошка7Синий!ДождьКактус`

4. Транслитерируй (опционально):
   `Koshka7Siniy!DozhdKaktus`

**Метод 3: Менеджер паролей**

Используй программу для генерации и хранения паролей:
- **Bitwarden** (бесплатный, рекомендуется)
- **1Password** (платный, очень удобный)
- **LastPass** (бесплатный базовый план)
- **KeePass** (бесплатный, локальный)

### Где хранить пароль

**✅ Безопасно:**
- Менеджер паролей (лучший вариант)
- Зашифрованная заметка в телефоне
- Записать на бумаге и хранить в сейфе/ящике

**❌ Небезопасно:**
- Файл "пароли.txt" на рабочем столе
- Заметка в телефоне без защиты
- Сообщение самому себе в мессенджере
- Стикер на мониторе
- Браузер (если компьютер общий)
- Один пароль для всех сайтов

### Как часто менять пароль

**Обязательно меняй пароль, если:**
- Подозреваешь, что его узнали
- Получил подозрительное письмо о входе
- Использовал на чужом компьютере
- Произошла утечка данных (проверь на haveibeenpwned.com)

**Регулярная смена:**
- Раз в 6-12 месяцев — хорошая практика
- Не обязательно, если пароль надёжный и уникальный

## Двухфакторная аутентификация (2FA)

### Что такое 2FA

**Обычный вход:**
```
Логин + Пароль → Доступ
```

**Вход с 2FA:**
```
Логин + Пароль + Код из телефона → Доступ
```

**Два фактора:**
1. **Знание** — то, что ты знаешь (пароль)
2. **Владение** — то, что у тебя есть (телефон с приложением)

**Почему это безопаснее:**
Даже если хакер узнает твой пароль, он не сможет войти без твоего телефона!

### Приложения для 2FA

**Рекомендуемые приложения:**

| Приложение | Платформы | Особенности |
|------------|-----------|-------------|
| **Google Authenticator** | Android, iOS | Простой, надёжный |
| **Authy** | Android, iOS, Windows, Mac | Синхронизация между устройствами |
| **Microsoft Authenticator** | Android, iOS | Интеграция с Microsoft |
| **Aegis** | Android | Открытый код, бесплатный |

**Как установить Google Authenticator:**

**Android:**
1. Открой Google Play
2. Найди "Google Authenticator"
3. Нажми "Установить"

**iOS:**
1. Открой App Store
2. Найди "Google Authenticator"
3. Нажми "Загрузить"

6. Нажми "Подтвердить"

**Если код не принимается:**
- Проверь, что вводишь КОД ДЛЯ NEMAKS (не другого сервиса!)
- Подожди новый код (они меняются каждые 30 сек)
- Проверь, что время на телефоне правильное (автоматическое)

### Что делать, если потерял телефон

**Если есть резервные коды:**
1. На странице входа введи логин и пароль
2. Когда попросит код 2FA, нажми "Использовать резервный код"
3. Введи ОДИН из сохранённых резервных кодов
4. Войдёшь в аккаунт
5. Немедленно: Настройки → Безопасность → Отключи 2FA
6. Настрой 2FA заново на новом телефоне

**Если НЕТ резервных кодов:**
1. Обратись в поддержку Nemaks
2. Докажи, что ты владелец аккаунта:
   - Email, указанный при регистрации
   - Ключ лицензии (если помнишь)
   - Историю платежей
   - Другие доказательства
3. Поддержка отключит 2FA вручную (может занять время)

### Как отключить 2FA

1. Настройки → Безопасность → Двухфакторная аутентификация
2. Нажми "Отключить 2FA"
3. Введи текущий 6-значный код из приложения
4. Подтверди действие
5. 2FA отключена

**Когда может понадобиться отключить:**
- Смена телефона
- Проблемы с приложением
- Переход на другой аутентификатор

## Шифрование сообщений (E2E)

### Как работает шифрование

**Без шифрования (небезопасно):**
```
Ты: "Привет!"
      │
      ▼
   [Сервер видит: "Привет!"]
      │
      ▼
Друг: "Привет!"
```

**С E2E-шифрованием (безопасно):**
```
Ты: "Привет!"
      │
      ▼ Шифрование твоим ключом
   [Сервер видит: "x7Hk9mNp2qWe..."]
      │
      ▼ Расшифровка ключом друга
Друг: "Привет!"
```

### Криптография простым языком

**Аналогия с сейфом:**

1. У тебя есть два ключа:
   - **Публичный** (открытый) — как адрес, даёшь всем
   - **Приватный** (секретный) — как ключ от сейфа, только у тебя

2. Друг хочет отправить сообщение:
   - Берёт твой ПУБЛИЧНЫЙ ключ (он общедоступен)
   - Кладёт сообщение в "сейф" и закрывает твоим публичным ключом
   - Отправляет

3. Ты получаешь:
   - Берёшь свой ПРИВАТНЫЙ ключ
   - Открываешь "сейф"
   - Читаешь сообщение

4. Никто другой не может открыть:
   - У них нет твоего приватного ключа
   - Даже создатель "сейфа" (друг) не может его открыть после закрытия

### Какие сообщения шифруются

| Тип | Шифрование | Примечание |
|-----|------------|------------|
| Личные сообщения (DM) | ✅ Всегда E2E | Автоматически |
| Групповые DM | ✅ E2E | До 10 человек |
| Голосовые звонки | ✅ E2E | Аудио и видео |
| Каналы гильдий | ⚠️ Опционально | По умолчанию нет |
| Голосовые каналы гильдий | ⚠️ Опционально | По умолчанию нет |

**Почему каналы гильдий не зашифрованы по умолчанию:**
- Много участников = сложное шифрование
- Модерация требует доступа к сообщениям
- Снижает производительность
- Можно включить для приватных каналов

### Индикаторы шифрования

**Иконки в чате:**
- 🔒 Замок — чат полностью зашифрован
- 🔓 Открытый замок — без E2E шифрования
- ⚠️ Предупреждение — проблема с ключами

**Что означает ⚠️ предупреждение:**
- Ключи собеседника изменились
- Возможно, он переустановил приложение
- Или кто-то пытается перехватить сообщения
- Нужно подтвердить личность собеседника

### Верификация ключей

Чтобы убедиться, что общаешься именно с другом, а не с хакером:

1. Открой DM с другом
2. Нажми на его имя в заголовке
3. Выбери "Проверить шифрование"
4. Появится набор цифр/эмодзи

**Как проверить:**
1. Позвони другу (по телефону, НЕ через Nemaks)
2. Продиктуй свои цифры/эмодзи
3. Он диктует свои
4. Если совпадают — всё в порядке!
5. Если не совпадают — возможен перехват

### Экспорт и импорт ключей

**Зачем это нужно:**
При смене устройства твои ключи НЕ переносятся автоматически.
Без старых ключей ты не сможешь читать старые сообщения!

**Как экспортировать ключи:**
1. Настройки → Безопасность → Ключи шифрования
2. Нажми "Экспортировать ключи"
3. Придумай пароль для защиты файла
4. Сохрани файл в безопасное место

**Как импортировать на новом устройстве:**
1. Настройки → Безопасность → Ключи шифрования
2. Нажми "Импортировать ключи"
3. Выбери файл
4. Введи пароль
5. Ключи восстановлены!

- Раз в месяц для профилактики
- После путешествий
- После смены пароля

## Защита от фишинга

### Что такое фишинг

**Фишинг** — это когда мошенники притворяются Nemaks (или другим сервисом), чтобы украсть твои данные.

**Примеры фишинга:**

**1. Поддельные письма:**
```
От: security@nemaks-support.com (ПОДДЕЛЬНЫЙ!)
Тема: Ваш аккаунт будет заблокирован!

Уважаемый пользователь!

Мы обнаружили подозрительную активность на вашем аккаунте.
Чтобы избежать блокировки, подтвердите данные:

[НАЖМИТЕ ЗДЕСЬ] ← ведёт на поддельный сайт
```

**2. Поддельные сайты:**
```
Настоящий:  nemaxks-4.replit.app
Поддельный: nemaks-free.xyz
Поддельный: nemaks.login.com
Поддельный: nemaxks4.ru
```

**3. Мошенники в DM:**
```
"Привет! Я модератор Nemaks. 
Для проверки аккаунта пришли мне пароль."
```

- Видно, кто сейчас в канале
- Много людей одновременно
- Общение продолжается, даже если кто-то выходит

### Режимы активации микрофона

**1. Voice Activity (Голосовая активация)**

Микрофон включается автоматически, когда ты говоришь.

**Настройка:**
1. Настройки → Голос и видео
2. Режим ввода → "Голосовая активация"
3. Настрой чувствительность

**Ползунок чувствительности:**
```
Тихо ────────●─────────── Громко
        (порог активации)
```

- Сдвинь левее = нужно говорить громче для активации
- Сдвинь правее = включается от тихих звуков

**Проблемы и решения:**

| Проблема | Решение |
|----------|---------|
| Микрофон включается от фоновых шумов | Сдвинь порог левее |
| Микрофон не включается, когда говорю | Сдвинь порог правее |
| Обрезает начало слов | Включи "Автоматически определять" |

**2. Push to Talk (PTT) — Нажми и говори**

Микрофон включается только когда ты держишь клавишу.

**Настройка:**
1. Настройки → Голос и видео
2. Режим ввода → "Push to Talk"
3. Нажми "Записать клавишу"
4. Нажми нужную клавишу (например, `V`, `~`, или боковая кнопка мыши)
5. Сохрани

**Преимущества PTT:**
- Никаких фоновых шумов
- Полный контроль
- Идеально для шумного окружения

**Недостатки PTT:**
- Нужно держать клавишу
- Можно забыть нажать

### Тестирование микрофона

**Как проверить:**
1. Настройки → Голос и видео
2. Найди раздел "Проверка микрофона"
3. Нажми "Давайте проверим"
4. Говори — должен двигаться индикатор громкости
5. Послушай запись своего голоса

```
│  ^--- индикатор громкости                       │
│                                                 │
└─────────────────────────────────────────────────┘
```

**Шумоподавление:**
1. Настройки → Голос и видео
2. Включи "Шумоподавление"
3. Фильтрует фоновые шумы (клавиатура, вентилятор, улица)

- Помогает, если используешь колонки вместо наушников

**Автоматическая регулировка громкости:**
- Выравнивает уровень звука
- Полезно, если говоришь то тихо, то громко

## Качество связи

### Что влияет на качество

**1. Скорость интернета**

| Действие | Минимум | Рекомендуется |
|----------|---------|---------------|
| Только голос | 1 Мбит/с | 3 Мбит/с |
| Голос + видео (720p) | 3 Мбит/с | 5 Мбит/с |
| Видео (1080p) | 5 Мбит/с | 10 Мбит/с |
| Стрим экрана | 5 Мбит/с | 15 Мбит/с |
| Стрим + видео | 10 Мбит/с | 20 Мбит/с |

**Как проверить скорость:**
Зайди на speedtest.net

**2. Пинг (задержка)**

| Пинг | Качество связи |
|------|----------------|
| 0-50 мс | Отлично |
| 50-100 мс | Хорошо |
| 100-200 мс | Нормально (небольшие задержки) |
| 200+ мс | Плохо (заметные задержки) |

**3. Стабильность**

Даже быстрый интернет плох, если нестабильный:
- Wi-Fi может прерываться
- Проводное подключение надёжнее
- VPN может ухудшать качество

### Индикаторы качества

Рядом с аватарами в голосовом канале:
- 🟢 Зелёный — отличное соединение
- 🟡 Жёлтый — среднее, возможны проблемы
- 🔴 Красный — плохое соединение

### Решение проблем

**Проблема: Тебя не слышат**

| Причина | Решение |
|---------|---------|
| Микрофон выключен | Нажми 🎤 |
| Неправильное устройство | Проверь настройки → Устройство ввода |
| Низкая громкость | Увеличь громкость микрофона |
| PTT не нажат | Зажми клавишу Push-to-Talk |
| Порог чувствительности | Настрой чувствительность |
| Браузер заблокировал | Проверь разрешения сайта |

**Проблема: Ты никого не слышишь**

| Причина | Решение |
|---------|---------|
| Звук отключён | Нажми 🔊 |
| Неправильное устройство | Проверь настройки → Устройство вывода |
| Низкая громкость | Увеличь громкость в настройках |
| Системная громкость | Проверь микшер Windows |
| Наушники не подключены | Проверь кабель |

**Проблема: Эхо**

| Причина | Решение |
|---------|---------|
| Звук из колонок попадает в микрофон | Используй наушники |
| Громкие колонки | Уменьши громкость |
| Эхоподавление выключено | Включи в настройках |

**Проблема: Фоновый шум**

| Причина | Решение |
|---------|---------|
| Шумное окружение | Используй Push-to-Talk |
| Шумоподавление выключено | Включи шумоподавление |
| Чувствительный микрофон | Увеличь порог активации |
| Вентилятор/кондиционер | Отодвинь микрофон |

**Проблема: Прерывистый звук**

| Причина | Решение |
|---------|---------|
| Нестабильный интернет | Перезагрузи роутер |
| Wi-Fi далеко | Подойди ближе к роутеру |
| Перегруженный канал | Используй проводное подключение |
| Много устройств в сети | Отключи другие устройства |

## Особенности голосовых каналов

### AFK-канал

**Что это:**
Специальный канал, куда автоматически перемещаются неактивные пользователи.

**Как работает:**
1. Владелец гильдии настраивает AFK-канал и таймаут
2. Если ты не говоришь и не двигаешь мышью N минут
3. Тебя автоматически перемещают в AFK-канал

**Настройка (для владельца):**
1. Настройки гильдии → Обзор
2. Канал неактивности → выбери голосовой канал
3. Таймаут неактивности → 1, 5, 15, 30, 60 минут

### Лимит участников

**Как настроить (для владельца/админа):**
1. Настройки канала
2. Лимит пользователей → выбери число (0 = без ограничений)

**Что происходит при лимите:**
- Показывается `(2/5)` — 2 из 5 мест занято
- Когда канал полный — войти нельзя
- Модераторы могут войти даже в полный канал

### Приватные голосовые каналы

**Как создать:**
1. Создай обычный голосовой канал
2. Настройки канала → Права доступа
3. Для @everyone:
   - Просмотр канала: ❌
   - Подключение: ❌
4. Для нужной роли (например, @VIP):
   - Просмотр канала: ✅
   - Подключение: ✅

Теперь канал видят и могут войти только VIP!

### Stage-каналы (Сцена)

**Что это:**
Специальный канал для мероприятий, лекций, подкастов.

**Структура:**
- Спикеры — говорят со сцены
- Аудитория — слушает (микрофон выключен)

**Особенности:**
- Аудитория может "поднять руку" 🖐️
- Модератор приглашает на сцену
- Идеально для больших мероприятий

**Как использовать:**
1. Создай Stage-канал
2. Спикеры заходят и начинают говорить
3. Слушатели заходят как аудитория
4. Модератор управляет, кто на сцене

## Советы для голосового общения

### Этикет голосовых каналов

1. **Используй наушники** — предотвращает эхо
2. **Выключай микрофон, когда не говоришь** — меньше шума для других
3. **Не кричи в микрофон** — настрой громкость
4. **Предупреждай об AFK** — "Отойду на минуту"
5. **Не включай музыку в микрофон** — используй бота
6. **Не ешь в микрофон** — выключай на время еды
7. **Уважай PTT** — если принято в гильдии

### Технические советы

1. **Перед важным созвоном** — проверь микрофон и интернет
2. **Закрой лишние программы** — меньше нагрузки на компьютер
3. **Перезагрузи браузер** — если есть проблемы
4. **Используй проводной интернет** — стабильнее Wi-Fi
5. **Обнови браузер** — старые версии могут глючить
6. **Не стримь через VPN** — ухудшает качество
