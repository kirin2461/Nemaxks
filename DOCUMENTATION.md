## Обзор проекта

**Nemaks** — современная коммуникационная платформа, аналог Discord, с расширенными функциями геймификации, безопасности и монетизации.

### Ключевые возможности

- Реалтайм-мессенджер с WebSocket
- Голосовые и видеозвонки (WebRTC)
- Каналы и гильдии (сервера)
- Истории (24-часовые)
- AI-ассистент JARVIS
- Система рейтингов (5 звезд)
- Многоязычность (RU/EN)
- Сквозное шифрование
- Система лицензий

## Система лицензирования

### Тарифы

| Тип | Срок | Цена (RUB) | Цена (USD) |
|-----|------|------------|------------|
| MONTHLY | 30 дней | 50₽ | $1.00 |
| QUARTERLY | 90 дней | 125₽ | $1.50 |
| YEARLY | 365 дней | 600₽ | $8.00 |

### Формат ключа

```
NEMKS-XXXXX-XXXXX-XXXXX
```

- Префикс: `NEMKS`
- 4 сегмента через дефис
- 23 символа всего
- Только заглавные буквы и цифры

### Преимущества лицензии

- Полный доступ к регистрации и авторизации
- Отсутствие системной рекламы
- Возможность подачи заявок на рекламу

### Стекирование

При активации нового ключа срок добавляется к существующему:
- Текущая лицензия: до 01.02.2026
- Активация 30-дневного ключа
- Новый срок: до 03.03.2026

## Аутентификация и безопасность

### JWT токены

- **Access Token**: 15 минут
- **Refresh Token**: 7 дней
- Ротация при каждом обновлении

### Двухфакторная аутентификация (2FA)

- TOTP (Google Authenticator, Authy)
- QR-код для настройки
- 8 резервных кодов (bcrypt хеш)

### Защита от брутфорса

- 5 неудачных попыток = блокировка 15 минут
- Логирование всех попыток входа

### Управление сессиями

- Отслеживание устройств и IP
- Просмотр активных сессий
- Отзыв отдельных/всех сессий

### Blacklist токенов

- Хранение в Redis (fallback: память)
- Автоочистка истекших записей

### HTTP заголовки безопасности

- Content-Security-Policy
- X-Frame-Options
- Strict-Transport-Security
- X-Content-Type-Options

### Санитизация контента

- Все пользовательский контент очищается от XSS
- HTML теги экранируются

## Сквозное шифрование

### Алгоритмы

- **X25519** — обмен ключами
- **XSalsa20-Poly1305** — шифрование

### Типы чатов

| Тип | E2E | Причина |
|-----|-----|---------|
| Личные сообщения | Да | Приватность |
| Групповые каналы | Опционально | Выбор владельца |
| JARVIS чаты | Нет | AI требует доступ |
| Публичные каналы | Нет | Публичный контент |

### Хранение ключей

- Приватный ключ шифруется на клиенте
- На сервере только зашифрованная версия
- Групповые ключи распределяются участникам

### Доступ администратора

- Пользователь может предоставить временный доступ
- Ключ шифруется для Super Admin
- Автоматическое истечение
- Возможность отзыва

## Геймификация

### Фаза 1: Базовая геймификация

#### Достижения

- 16 достижений по категориям
- Категории: social, voice, content, progression, reputation, loyalty
- Редкость: common, uncommon, rare, epic, legendary

#### Уровни и XP

| Действие | XP |
|----------|-----|
| Сообщение | +5 |
| Реакция | +2 |
| Голосовое время | +1/мин |
| Пост | +10 |
| Голосование | +5 |
| Создание опроса | +15 |

Формула уровня: `XP * 1.15^level`

#### Опросы

- Множественные варианты
- Срок истечения
- Одиночный/множественный выбор
- Анонимное голосование

#### Пользовательские статусы

- Текст + эмодзи
- Авто-истечение: 30мин, 1час, 4часа, сегодня
- Пресеты (Working, Gaming, Music)

#### Исчезающие сообщения

- Включение по беседам
- Варианты: 1мин, 5мин, 1час, 1день, 1неделя
- Фоновая очистка каждую минуту

## Структура базы данных

### Основные таблицы

```
users
├── id (PK)
├── username
├── email
├── password_hash
├── role (user/moderator/admin/super_admin)
├── is_banned
├── two_factor_enabled
├── created_at
└── updated_at

guilds
├── id (PK)
├── name
├── description
├── owner_id (FK → users)
├── icon_url
├── created_at
└── is_public

channels
├── id (PK)
├── guild_id (FK → guilds)
├── name
├── type (text/voice/video)
├── is_private
└── position

messages
├── id (PK)
├── channel_id (FK → channels)
├── author_id (FK → users)
├── content
├── is_edited
├── created_at
└── expires_at

license_keys
├── id (PK)
├── key (unique)
├── type (MONTHLY/QUARTERLY/YEARLY)
├── duration_days
├── price_rub
├── is_used
├── used_by (FK → users)
├── used_at
└── created_at

user_licenses
├── id (PK)
├── user_id (FK → users)
├── license_key_id (FK → license_keys)
├── type
├── activated_at
├── expires_at
└── is_active

fraud_alerts
├── id (PK)
├── user_id (FK → users)
├── type
├── severity
├── content
├── status
└── created_at
```

## Развертывание

### Требования

- Go 1.21+
- Node.js 20+
- PostgreSQL 15+
- Redis (опционально)

### Переменные окружения

```env
DATABASE_URL=postgresql://user:pass@host:5432/nemaks
JWT_SECRET=your-secret-key
PORT=8000
```

### Запуск

```bash
# Backend
cd backend && go run .

# Frontend
cd frontend && npm run dev -- --host 0.0.0.0 --port 5000
```

### Поток авторизации

```
/welcome → /activate → /auth → /dashboard
```

1. Пользователь видит презентацию
2. Переходит на активацию лицензии
3. Вводит ключ или покупает
4. Регистрируется/входит
5. Попадает на главную
